# Rookie 的笔记

一个中文静态笔记站，首页支持按主题筛选，以及搜索标题、摘要和主题。初始收录的是三篇示例笔记。

## 本地预览

在仓库根目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000/`。网站使用 HTML、CSS 和 JavaScript，无需安装前端依赖或构建。

## 添加笔记

1. 复制 `notes/` 中的一篇文章，修改标题、主题、日期和正文。
2. 在 `index.html` 的笔记列表中加入入口，更新链接、标题、摘要和日期。现有笔记按日期从新到旧排列。
3. 如需新增主题，在首页筛选按钮中加入同名主题，确保 `data-topic` 和列表里的主题文字一致。
